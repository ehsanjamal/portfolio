Smart Plant Disease Detection for Sustainable Farming

Lead Developer · Final Year Project (Group) · 2026

  • Curated a 24-class, Sindh-relevant crop disease dataset (Cotton, Sugarcane, Mango, Rice, Wheat; ~15,250 images) by merging 4 Kaggle datasets.
  • Designed and trained an EfficientNetB3 + Squeeze-and-Excitation attention CNN, reaching ~94.5% validation accuracy with a two-phase (frozen + fine-tuning) pipeline.
  • Added data augmentation (brightness, rotation, color-shift) to improve robustness on real field images.
  • Built and deployed a Flask web app with HTML/CSS/JavaScript frontend for instant prediction and sustainable treatment guidance across all 24 classes.
  • Produced system architecture, flowcharts and technical documentation for the formal FYP evaluation.
